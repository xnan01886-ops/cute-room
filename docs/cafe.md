# Strawberry · 草莓云朵咖啡馆

从主导航的「咖啡馆」进入。独立于公主小屋，保留原有房间及交互。

## 玩法

1. 在制作台选择自制饮品或烘焙点心。饮品有 6 种杯底、5 种风味、温度和甜度；点心有舒芙蕾、切块蛋糕、纸杯蛋糕以及不同夹心。
2. 自选最多 3 种装饰、为配方命名。三维预览随配料改变，可旋转、缩放，也能切到咖啡馆全景。
3. 点击开始制作，再逐步操作。制作中会固定配方，进度完成后才能进入下一步；可取消并重新调整。
4. 完成后放入展示柜，查看美味、装饰、香气、饱腹四项游戏属性和特别标签。最多摆放 8 份。
5. 选择店里的客人，将成品端给它。每位客人每天用餐一次，匹配类型、风味会得到更多感谢星（1–3 颗，无付费机制）。
6. 喜欢的搭配可收进配方本，最多 12 张，支持调出、编辑和删除。

## 制作反馈的边界

「Null · 制作助手」明确标注为本地规则反馈。它根据材料、步骤、成品及招待事件产生文字，不调用 AI、不观看屏幕或摄像头。可把制作摘要带入现有聊天草稿，仍需手动发送；现有聊天尚未接入模型回复。

`game.js` 将事件保存在 `events` 中（最近 80 条）：`{id, at, action, payload}`，包含 ingredient、topping、start、process、step_complete、finish、serve 等。后续可由后端将这些结构化上下文交给模型；浏览器端不能存放模型 API 密钥。

当前所有数据在本次页面打开期间保留，切换应用栏目不会丢失；刷新、关闭页面后重置。没有数据库或账户同步。属性是游戏数值，不是真实味觉、营养或食品制作指导。

## 技术与验证

- React reducer 管理配方、步骤状态、展示柜、来客和反馈。
- Three.js 实体几何构建餐台、设备、甜点、饮品和动物，OrbitControls 支持旋转/缩放。
- 三维模块按需加载；静态场景仅在视角或状态改变时重绘。卸载释放几何体、材质和 WebGL 上下文。
- `npm run build` 构建。
- `npm run test:cafe` 验证到访边界、每日招待限制、偏好评分、容量限制、步骤计时、配方固定、取消和事件记录。
- 浏览器验证：舒芙蕾和调饮完整出品/招待流程、配方收藏调出、聊天草稿、切换栏目保留状态、三维场景及 390px / 320px 布局。

## Windows 更新现有预览分支

先在运行前端的终端按 Ctrl+C。打开项目的 `cute-room\frontend` 文件夹，在地址栏输入 `powershell` 并回车，依次运行：

```powershell
git switch strawberry-princess-room
git pull --ff-only
npm.cmd install
npm.cmd run dev
```

打开终端显示的本地地址，从导航进入「咖啡馆」。如 Git 提示本地改动冲突，保留文件并查看提示，不要使用强制重置或清理命令。
